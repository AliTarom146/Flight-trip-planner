# Flight Trip Planner

Project Video: https://youtu.be/w5ovAdwa91Q

## Project Overview

Flight Trip Planner is a simple Python program that helps users plan and manage trips. The user can enter a destination, flight cost, hotel cost, number of nights, and an activity. The program can then display the trip information, calculate the total trip cost, and remove a trip.

## Features

* Add a trip
* View saved trips
* Calculate the total trip cost
* Remove a trip
* Exit the program

## Python Concepts Used

This project uses concepts from Python Crash Course, Chapters 1–7, including:

* Variables
* Strings
* Integers and floats
* Lists
* Dictionaries
* `if`, `elif`, and `else` statements
* `for` loops
* `while` loops
* User input with `input()`

## How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or Terminal.
3. Run the program with:

```bash
python3 flight_trip_planner.py
```

4. Use the menu to add, view, calculate, or remove trips.

## Example

A user can enter:

* Destination: Paris
* Flight Cost: $500
* Hotel Cost: $1200
* Number of Nights: 7
* Activity: See the Eiffel Tower

The program stores this information and calculates the total trip cost as $1700.
